# Databootcamp-Regression-Competition-for-house-prices
Team members: Melody Zuo and Yihuan Zhang

## Project Overview

We worked with the housing dataset with 1,200 training houses and 260 test houses. We handled missing values and tested several models including Linear Regression, Polynomial Regression, Ridge Regression, and Random Forest.

We also created additional features based on house size, age, overall quality, and garage spaces. After comparing different models, we selected a Ridge Regression model with `alpha=10`.

Final Model Kaggle Public RMSE: 27,003.58788
